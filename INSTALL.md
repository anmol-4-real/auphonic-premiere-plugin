# Installing Awwphonic

1. Make sure Adobe Creative Cloud Desktop is installed and you're signed in (you already have this if you use Premiere Pro).
2. Double-click the file you were sent: `Awwphonic-vX.X.X.ccx`.
3. Click **Install** (or **Update**, if you already have it) in the Creative Cloud dialog that pops up.
4. Restart Premiere Pro if it was open.
5. Open the panel from **Window > Extensions > Awwphonic Audio Processor**.

That's it — no developer settings, no extra software.

## Updating later

Same steps, using the new `.ccx` file you're sent. It replaces your existing copy — you won't end up with two.

## If nothing happens when you double-click

Right-click the `.ccx` file, choose **Open With**, and pick **Creative Cloud** (or **Adobe Creative Cloud**) from the list.
